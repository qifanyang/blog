  spring不提倡使用getBean()访问容器,因为这样会对spring api产生依赖,使用xml的方式配置bean
也不会依赖spring api,但是我们一般使用的@Autowired来配置,这样子也对spring api产生依赖了
测试对使用了spring注解的类在没有spring jar包的情况下会报错么?

### 第一步,在有spring的环境下新建一个类,在字段上使用@Autowired
	import org.springframework.beans.factory.annotation.Autowired;

	public class Test {

   		@Autowired
    	private String name;

    	public String getName() {
        	return name;
    	}

   		public void setName(String name) {
        	this.name = name;
    	}
	}

### 第二步, 在输出的class目录下,使用jar cvf Test.jar test.class , 打包

### 第三步, 在一个没有spring依赖的项目中,添加对Test.jar的依赖,测试使用Test类,结果没有报错,但是无法使用反射访问注解

	public class Main {

    public static void main(String[] args) throws NoSuchFieldException {
        System.out.println("Hello World!");
        Test test = new Test();
        test.setName("test no autowired annotation");
        System.out.println(test.getName());
        Field name = test.getClass().getDeclaredField("name");
        Annotation[] annotations = name.getAnnotations();//没有报错, 但是注解数组为空集合
        for(Annotation annotation : annotations){
            System.out.println(annotation.getClass());
        }
    }
	}
	


### 第四步, 原因分析

	分析了源码后,发现使用反射访问注解,返回的Annotation其实是返回的使用动态代理创建的一个对象(如果注解能够找到的话)
	 public static Annotation annotationForMap(final Class<? extends Annotation> var0, final Map<String, Object> var1) {
        return (Annotation)AccessController.doPrivileged(new PrivilegedAction() {
            public Annotation run() {
                return (Annotation)Proxy.newProxyInstance(var0.getClassLoader(), new Class[]{var0}, new AnnotationInvocationHandler(var0, var1));
            }
        });
    }

	在annotation上调用annotationType()返回Class<? extends Annotation> var0,该值为代表annotation的类,比如Autowired


	为什么没有报错?
	 AnnotationParser.parseAnnotations(...)完成注解解析,从使用了注解的类class中查找注解,因为没有注解定义,所以返回为空,而且在解析的时候
	 默认是吃掉异常的,NoClassDefFoundError,TypeNotPresentException,都不抛出, 经本地测试会抛出TypeNotPresentException异常
	,所以每次访问注解的时候,如果注解类不存在是会抛出异常的,频繁访问的话会有频繁抛出异常,会有效率问题

	所以依赖的spring注解的类在非spring环境使用,访问注解是会抛出异常的,频繁访问会有性能问题,如果只是在启动程序时访问一次还可以接受
